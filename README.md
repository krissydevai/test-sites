# test-sites

A collection of front-end clones and demo builds. Each site lives in its own folder and is published via GitHub Pages.

## Live

- **Landing page:** https://secrettechjunkie.github.io/test-sites/
- **Game Nerdz** (e-commerce storefront clone): https://secrettechjunkie.github.io/test-sites/gamenerdz/

## Structure

```
test-sites/
├── index.html      landing page linking to each site
└── gamenerdz/      Game Nerdz storefront clone
    └── index.html
```

Static HTML/CSS — no build step. Add a new site by creating a folder with its own `index.html` and linking it from the landing page.
